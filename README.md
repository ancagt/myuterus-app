# MyUterus (TypeScript)

Independent TypeScript copy of MyUterus: a React/Vite client and an Express/Node.js API.

Use Node.js 18 or newer. Run `npm install` and `npm run dev` from this directory.
The client runs at http://localhost:5175 and the API at http://localhost:4001.
`npm run typecheck` checks both workspaces; `npm run build` builds both;
`npm start` starts the built API. The cycle calendar saves period days locally in the browser.

The original JavaScript project remains unchanged in the neighboring `myuterus` directory.
